# 🧮 Multi-Theme Calculator

A sleek, modern, and fully responsive **Multi-Theme Calculator** web application built using **React.js**. This project features a fully functional arithmetic engine along with a dynamic theme-switching mechanism (Light, Dark, and Cyberpunk/Custom modes) that saves user preferences locally.

---

## 🚀 Features

- **Standard Arithmetic Operations:** Supports addition, subtraction, multiplication, division, and percentage calculations.
- **Dynamic Theme Switching:** Switch between multiple beautiful themes (Light Mode, Dark Mode, and Vivid/Cyberpunk Mode) instantly.
- **Theme Persistence:** Uses `localStorage` to remember the user's preferred theme even after refreshing the page or restarting the browser.
- **Smart Input Handling:** Prevents invalid decimal placements and handles errors (like division by zero) gracefully.
- **Keyboard Friendly & Responsive:** Clean layout that looks stunning on mobile devices, tablets, and desktops.

---

## 🛠️ Tech Stack Used

- **Frontend:** React.js (Functional Components)
- **Hooks Used:** - `useState` for state management of inputs, results, and current theme.
  - `useEffect` for synchronized theme updates with the DOM and LocalStorage.
- **Styling:** Modern CSS3 with CSS Custom Variables (Variables make the instant theme-switching work flawlessly).
